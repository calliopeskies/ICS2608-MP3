# MP3 - Login and CharacterCounter
## Project Overview
Develop a Java Web Application using Java Servlets, JSP (JavaServer Pages), and the Deployment Descriptor (web.xml). The application must authenticate a user, accept a string, and display statistics about the characters entered.

Use NetBeans with Apache Ant as the build tool. Do not use Maven or Gradle.

Your application must contain at least two servlets:
1. LoginServlet – Validates the user's login credentials.
2. CharacterCountingServlet – Processes the input string and counts its characters.

The application must also use a ServletContextListener to initialize the current date and time and ServletContext to provide a common header and footer for all JSP pages.

## Functional Requirements
A. Login Page
B. Login Validation
C. Success Page
D. Character Processing
E. Error Page
